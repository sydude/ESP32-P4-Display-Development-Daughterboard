# Phase 2 custom footprints

The schematic deliberately assigns `Phase2:` names to packages whose exact
land patterns are not present in the stock KiCad library. These footprints are
not fabricated or guessed during schematic capture. They must be created from
the cited manufacturer package drawings and independently checked before PCB
placement is frozen.

Required custom footprints are listed in `docs/design-notes/schematic-review.md`.
